# Guarda-Roupa · Laura Corrêa

Site estático do guarda-roupa: 144 peças recortadas, looks salvos por estação e
tratamento de foto por IA direto no navegador.

- `index.html` · `css/app.css` · `js/app.js` · `js/data.js` (catálogo) · `img/` (recortes 512px)
- Dados (looks, peças novas, fotos tratadas) ficam no **localStorage** do aparelho.
  Use **Backup** na engrenagem pra levar pra outro aparelho.
- IA: chave do Gemini ou do Grok, guardada só no navegador. Nada de servidor.
